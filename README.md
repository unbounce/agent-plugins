# Unbounce agent plugins

The public marketplace for **Unbounce's agent plugins** — installable across both
the Claude (`.claude-plugin/`) and the Codex / ChatGPT (`.agents/`) ecosystems.
The marketplace identity is `unbounce`; its first plugin is **`unbounce-mcp`**,
which brings Unbounce landing-page authoring and management to your assistant.

> **Status: private, pre-GA.** This repository is not yet public and is not yet
> listed in any assistant directory. Access is limited while the connector's
> sign-in allowlist is in place.

## Layout

This repository is **multi-package**. It owns its own shell — this `README`, the
license, `.github/`, and the two marketplace aggregates below — while each plugin's
own source repository owns the contents of its `plugins/<name>/` subtree.

```
.claude-plugin/marketplace.json   # Claude marketplace aggregate (lists every plugin)
.agents/plugins/marketplace.json  # Codex / ChatGPT marketplace aggregate
plugins/<name>/                    # one directory per plugin (generated by its source repo)
```

Plugin subtrees are **generated mirrors** — they are published here automatically
from each plugin's source repository, not edited by hand. `unbounce-mcp` is
mirrored from [`unbounce/unbounce-mcp`](https://github.com/unbounce/unbounce-mcp).

## Installing (internal validation)

While the repository is private, an authorized Unbouncer can add it from the
Claude Code CLI using their own repository access:

```
/plugin marketplace add unbounce/agent-plugins
/plugin install unbounce-mcp@unbounce
```

The first time a tool runs you'll be asked to sign in to Unbounce. Public,
directory-listed install instructions will replace this section at GA.
